# TabOnce Privacy Policy

Effective: August 28, 2026

TabOnce is designed so that its author does not collect, receive, or have access to any user data.
It has no analytics, tracking, advertising, accounts, or developer-operated servers. All extension
functionality runs within the user's browser.

## Data handled

To identify duplicate tabs and focus an existing match, TabOnce processes the following data within
the user's browser:

- The URLs of open and newly created tabs, to determine whether they match a user-defined rule.
- The destination URL of a clicked link on a site for which the user has explicitly granted access,
  to determine whether a matching tab is already open.
- User-defined matching rules and preferences.

This data is used only while providing the extension's user-facing functionality. Tab and link URLs
are not retained as browsing history by TabOnce and are never sent to the author or any
developer-operated service.

TabOnce does not collect names, email addresses, authentication information, financial information,
health information, personal communications, location information, or any other personal data.

## Storage and transmission

User-defined rules and preferences are stored using the browser's extension storage API. Depending
on the user's browser and sync settings, the browser provider may synchronize these settings between
the user's devices using its own sync mechanism. This synchronization is controlled by the browser
provider and the user, not by TabOnce or its author. The author cannot access synchronized data.

TabOnce does not transmit data to the author or to any server or service operated or selected by the
author.

## Data sharing and use

Because the author does not receive user data, there is no user data for the author to sell, share,
retain, analyze, or disclose. TabOnce does not use data for advertising, analytics, profiling,
creditworthiness, lending, or any purpose unrelated to preventing duplicate tabs.

## Transparency and verification

TabOnce is fully open source and licensed under the
[MIT License](https://github.com/dkarter/tab-once/blob/main/LICENSE). Its source code, build scripts,
and release workflow are publicly available at <https://github.com/dkarter/tab-once>.

[Published releases](https://github.com/dkarter/tab-once/releases) include source and browser
packages with SHA-256 checksums. Releases are immutable after publication, and GitHub automatically
creates a cryptographically verifiable release attestation covering the release tag, commit, and
assets. This allows the extension's source and published artifacts to be independently audited and
verified.

## Data control

Users can remove stored rules from the extension's options page. Users can revoke site access from
the extension or browser settings. Browser-synchronized settings are managed through the user's
browser sync controls.

## Changes

Material changes to this policy will be published with an updated effective date.
